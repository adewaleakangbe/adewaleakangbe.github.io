# Adewale Akangbe Portfolio

This is a dependency-free GitHub Pages portfolio for Adewale Akangbe, an AI engineer and researcher working across agentic systems, medical LLMs and cloud infrastructure.

The site includes the portrait in `linkedinphto (1).png`. Keep the image in the repository root when publishing so the hero image loads correctly.

## Publish

1. On GitHub, create a public repository named `adewaleakangbe.github.io`.
2. Upload `index.html`, `styles.css`, `og.png`, and `linkedinphto (1).png` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. The site will appear at `https://adewaleakangbe.github.io`.
